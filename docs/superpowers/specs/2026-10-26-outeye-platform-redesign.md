## 五、UI 设计系统（v1.1 全面升级）

### 5.1 设计概念：观测台（Observatory）

外眼的本义是**观看**——整个官网做成一座"观测台"：深空为幕、地球为对象、产品光点为焦距、经纬刻度为界面语言、矿物颜料为光谱。此概念从主题自身长出（传播=看见与被看见；太虚册工笔重彩的矿物色基因），与任何默认模板脸区隔。

三个视觉矿脉，执行时只用其克制子集：
1. **观测美学**：夜景地球、光点引线标注（天文图式）、球体刻度环——仅此三处，不做全站 HUD 化
2. **矿物颜料光谱**：四场景四色 = 中国画经典矿物色（石青/朱砂/石绿/泥金）——与太虚册美术（"矿物色感：石青/石绿/朱砂系"）家族同源
3. **中文排印**：宋体宣言、竖排场景名（2–4 字标签专用，正文绝不竖排）——美术馆目录气质

### 5.2 色彩 Token

| Token | 值 | 用途 |
|-------|-----|------|
| `--sky` | #0A0E1A | 首屏深空（带蓝墨，配夜景地球） |
| `--paper` | #FAF9F5 | 内页宣纸底 |
| `--ink` | #1C1B18 | 正文墨 |
| `--ink-2` | #6B6862 | 次级文字 |
| `--azurite` 石青 | #3A7CA5 | 传播研究 |
| `--cinnabar` 朱砂 | #B03A2E | 智能创作 |
| `--malachite` 石绿 | #3E7C5B | 文化教育 |
| `--gold` 泥金 | #C9A227 | 跨文化沟通 |
| `--lab-gray` | #8A8578 | 实验区/弱化 |

- 四色分离度：蓝/红/绿/金，色盲可辨（另以图标+文字标注场景，不单靠颜色）。
- 深空底上的文字版四色提亮变体（+25% 亮度），保证对比度 ≥4.5:1。
- **禁用**：渐变横幅、青紫 AI 渐变、玻璃拟态、阴影卡片堆。

### 5.3 排印 Token

| 层 | 规格 |
|----|------|
| 宣言（首页） | 思源宋体 Light 400，clamp(28px, 5vw, 56px)，行高 1.35，字距 +0.02em |
| 产品名/H2 | 思源宋体 Bold 700 |
| 正文 | 系统黑体栈（PingFang/微软雅黑），15–16px，行高 1.8，行长 ≤65ch |
| 数据数字 | tabular-nums；大数字 Geist/Sans，标签用宋体小字 |
| 竖排场景名 | writing-mode: vertical-rl，宋体，仅限 2–4 字场景/分组标签 |

- 字体自托管：移植太虚册 `build_font_subset.py` 管线（扫描站内文案 → 子集 woff2 <200KB）。
- **链接样式**：底部细线（1px 场景色），hover 色变+细线加粗；**禁用 '→' 后缀与全大写 eyebrow**。

**地球光点（位置=服务地域/故事发生地）：** OutSight→纽约(40.7,-74.0)石青；外刊精读→伦敦(51.5,-0.1)石绿；Pulse→上海(31.2,121.5)石青；太虚册→北京(39.9,116.4)朱砂；**《雅怀》→青岛(36.07,120.38)**（私立青岛大学故地）朱砂；**《四方风物》→四点**：裕固族·肃南草原(38.8,99.6)/满族·赫图阿拉(41.7,124.7)/彝族·石屏(23.7,102.5)/汉族·中原(34.7,113.6) 朱砂（一族一点，四点同作品）；OutEdu→威海(37.5,122.1)石绿；稷下→临淄(36.8,118.3)石绿；PinyinLab→巴厘岛(-8.4,115.2)石绿；译界→伊斯坦布尔(41.0,28.9)泥金；六爻→西安(34.3,108.9)灰（弱）。光点构成"外眼观测地图"：研究触角伸向世界媒体之都，创作故事扎根中国大地。

**交互流与动效预算（全部预算给地球）：**
1. 进场编排一次：地球淡入（占位→清晰）→ 光点按场景依次点亮（1.2s）→ 宣言逐行上浮
2. hover 光点：球体停转；光点放大 1.5× + **引线拉出侧边标注卡**（天文图式：细线 + 产品名 + 身份短语 + 域名），非普通浮卡
3. click → 产品详情；点击光点时同步 sr-only 列表高亮（无障碍等价入口）
4. 光点常态呼吸：透明度 0.65–1.0 正弦，周期 3s；弧线低频脉冲（0.2Hz）
5. `prefers-reduced-motion`：全停，静态高亮
6. 移动端 <768px：静态球图 240px + 横滑产品 chips（≥44px 触控）

### 5.5 内页构图

- **/products 矩阵（目录式，非卡片网格）**：每场景一组——左缘竖排场景名（石青"传播研究"竖排宋体）+ 右侧产品行条目（行式：产品名·身份短语·状态徽章·域名，行 hover 场景色左缘线）。底部"更多实验"灰组。
- **/products/[id]**：场景色左缘纵贯条 → 产品名宋体大标 → 关键数据徽章行（tabular）→ 两三段叙事（问题→方案→成果）→ **证据链四联**（演示/代码/报告/日志，行式链接）→ 技术要点 → 同场景相关产品横滑。
- **/platform**：母题大字 → 星型架构 SVG（一底座四场景，矿物四色）→ 底座三件套 → 跨产品数据总表（观测记录全量版）→ 团队与边界声明（AI 披露 + "产品各自独立，不共享用户数据"）。

### 5.6 交互与无障碍内置规则（Web Interface Guidelines 预埋）

- 触控目标 ≥44px；focus-visible 自定义样式（2px 场景色外框，不删 outline）
- 对比度：正文 ≥4.5:1，大字 ≥3:1；深空底文字用提亮变体
- prefers-reduced-motion / prefers-contrast 全尊重
- 地球提供 DOM 等价物：sr-only 产品列表 + 可见 chips（键盘可完整操作全站，不依赖球体拾取）
- 骨架占位（地球贴图加载期）+ 图片 alt + `content-visibility` 优化长页
- 实施完成后用 web-design-guidelines skill 跑正式审查（拉取最新规则）
